# TimeApp

TimeApp is a time management application built with Expo and React Native. It helps users track time and includes features like home screen widgets.

## Features

- **Time Tracking**: Manage your time effectively.
- **Home Screen Widgets**: Includes a "Year Progress" widget to visualize the remaining days of the year directly on your home screen.
- **Cross-Platform**: Runs on both Android and iOS.

## Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (LTS version recommended)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jatinsingh2003/Time-app.git
   cd Time-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Running the App

Start the development server:

```bash
npx expo start
```

This will display a QR code in the terminal. You can scan it with the **Expo Go** app on your Android or iOS device.

### Run on Android Emulator

```bash
npx expo run:android
```

### Run on iOS Simulator

```bash
npx expo run:ios
```

## Widgets

This app includes a native Android widget configuration. To see the widget in action, you may need to build the development client or run on an Android device/emulator.
