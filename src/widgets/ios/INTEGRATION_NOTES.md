## iOS Widget Integration Notes

This repository now includes the shared widget payload builder in:

- `src/widgets/widgetData.ts`
- `src/widgets/sharedWidgetModel.ts`
- `src/widgets/widgetSync.tsx`
- `src\widgets/ios/TimeWidget.swift`

To finish the real iOS widget integration, the native iOS project still needs:

1. An `ios/` project generated and committed.
2. A WidgetKit extension target added in Xcode.
3. An App Group configured for both the app target and widget target.
4. A small native bridge that:
   - writes the JSON payload from `widgetSync.tsx` into shared `UserDefaults`
   - triggers `WidgetCenter.shared.reloadAllTimelines()`
5. The Swift file in this folder copied into the widget extension target.

Expected shared storage values:

- App Group: `group.com.spritzstudio.dotchrono`
- UserDefaults key: `widgetPayload`

The payload is JSON generated by `buildWidgetPayload(...)` and supports:

- `year` widget mode
- `goal` widget mode

`life` intentionally falls back to `year` for iOS widget use in v1.
